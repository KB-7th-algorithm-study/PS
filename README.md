# 🚀 참여 방법

1. 본인 이름의 `브랜치`와 `폴더`를 생성해주세요.
2. 풀이한 코드는 본인 폴더에 넣은 후 `커밋`해주세요
3. 작업 완료 후 `main` 브랜치로 `Pull Request` 보낸 후 직접 `Merge`해주세요.
  <br/>
  
# 📅 스터디 규칙

- 매주 월/수/금 3문제를 풉니다.
- 못풀시 화/목/주말 이용해서 풉니다.
  <br/>

# 🛠️ 커밋 규칙

- 커밋 메세지 : [사이트] 문제이름

```
git commit -m "[프로그래머스] Hello"
git commit -m "[LeetCode] Hi"
```
  <br/>
  
# 🤝 PR 및 머지 규칙

- PR 제목 : [n주차] 이름
  ```
 	[13주차] 락쿠마
  ```
- 머지 방식은 `Squash and merge`로 해주세요
- 코드 리뷰는 환영입니다
