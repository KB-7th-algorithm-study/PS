# 🚀 참여 방법

1. 작업 시작 전 `main`을 최신 상태로 받은 뒤, 새 브랜치를 생성해주세요.
2. 풀이한 코드는 본인 폴더에 넣은 후 `커밋`해주세요
3. 작업 완료 후 `main` 브랜치로 `Pull Request` 보낸 후 직접 `Merge`해주세요.
4. 머지되면 브랜치는 원격에서 자동 삭제됩니다. 로컬 브랜치도 정리해주세요.
> ⚠️ 예전에 머지했던 브랜치 이어서 계속 쓰는거 금지!
